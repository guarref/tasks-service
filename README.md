Проект создан для демонстрации умения работать с gRPC на Go и может служить основой для реальных микросервисов.

Распределённая система на основе gRPC, разработанная на языке Go. Проект демонстрирует навыки backend-разработки: создание протоколов обмена, микросервисы для пользователей и задач, обработку запросов, а также работу с данными. Базовая архитектура для управления пользователями и их задачами с использованием gRPC для межсервисного взаимодействия.

Основные возможности:
1)Определение gRPC-сервисов и протоколов в Proto3
2)Реализация микросервисов (users-service и tasks-service) с gRPC-серверами
3)Интеграция с базой данных (PostgreSQL)
4)Валидация данных и обработка ошибок
5)Логирование и мониторинг

Технологии:
1)Go (Golang, v1.22+)
2)gRPC-Go — фреймворк для RPC
3)Protocol Buffers (protoc) — сериализация
4)GORM — ORM для работы с БД
5)Validator — валидация (github.com/go-playground/validator)
6)PostgreSQL — СУБД
7) go mod — управление зависимостями
